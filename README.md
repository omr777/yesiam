# YESIAM

**Your Expert System for Identity, Access, and Monitoring**

Plataforma web de gestión de identidades, accesos y auditoría para organizaciones.

## Tecnologías

- Angular y TypeScript
- Laravel y PHP
- MySQL 8
- Git y GitHub

## Funcionalidades previstas

- Gestión de identidades y departamentos
- Roles y permisos (RBAC)
- Solicitudes y aprobaciones de acceso
- Administración del ciclo de vida de identidades
- Auditoría de eventos de seguridad
- Panel administrativo

## Seguridad

El proyecto incorpora los principios Zero Trust:

1. Verify Explicitly
2. Use Least Privilege
3. Assume Breach
